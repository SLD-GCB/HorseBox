# HorseBox

HorseUI 面板的专用双端代理客户端。一套 Flutter 代码同时构建 Windows 和 Android，配置和节点全部来自 HorseUI 面板的订阅接口，客户端本身不包含任何节点。

- **Windows**：以子进程方式运行官方 `sing-box.exe`，支持 TUN 和混合端口，关闭窗口后驻留托盘。
- **Android**：通过 `libbox` + `VpnService` 接管流量，前台通知常驻，支持分应用代理。
- **附带工具**：内置 SSH 终端（含 SFTP 与本地端口转发）、面板登录密码本，不用再另装工具。

## 功能

**代理**

- **订阅拉取**：`https://面板地址/sub/<令牌>?target=singbox`
- **证书固定**：自签面板用 SHA-256 指纹校验，每次 TLS 握手都比对，不匹配直接断开
- **首次登录**：没有订阅时也能直接连面板，先建入站再配订阅
- **国内分流**：内置 `geosite-cn` / `geoip-cn`，国内域名和 IP 直连，其余走代理
- **自定义规则**：域名后缀、域名关键字、IP 段，可指定直连、代理或拦截
- **分应用代理（Android）**：选择走代理的应用和强制直连的应用，系统应用默认直连
- **节点管理**：自动选择、手动切换、单节点测速、全部测速
- **代理设置**：混合端口、TUN、TUN 栈（mixed / gvisor）、MTU、IPv6、局域网、DNS、私有域名映射；设置页按卡片分组，点进去再改
- **DNS**：沿用面板下发，或自定义 UDP / DoT / DoH
- **其他**：hosts 映射、连接列表、实时流量、日志、深色/浅色主题、Windows 数据目录自定义、口令加密的整包备份与恢复

**工具**

- **内嵌面板**：在客户端里直接打开 HorseUI 面板，安卓横屏沉浸式，Windows 左侧胶囊导航
- **配置（SSH）**：填 IP / 用户名 / 密码即可登录服务器，全屏终端，带 SFTP 文件传输和本地端口转发
- **密码本**：记录面板登录账号，登录面板时一键填入，密码加密存储
- **订阅用量**：订阅卡片与首页显示已用 / 总额 / 到期，数据实时取自面板，客户端不再本地累计

## 环境要求

- Flutter 3.x（Dart 3.13 及以上）
- Windows 构建：Visual Studio 2022，勾选「使用 C++ 的桌面开发」
- Android 构建：JDK 17 或 21、Android SDK、NDK `27.2.12479018`
- 不需要安装 Go，客户端后端是纯 Dart

主要依赖：`flutter_inappwebview`（内嵌面板）、`dartssh2` + `xterm`（SSH 终端）、`file_picker` + `path_provider` + `desktop_drop`（文件传输）、`cryptography`（本地加密）。

## 准备依赖

仓库不包含以下二进制文件，需要自行准备。

```
UI/android/app/libs/libbox.aar
```

也可以把文件放到 `core/libbox.aar`，再运行 `android/sync-libbox.bat` 复制过去。

### 2. sing-box.exe（Windows）

从 sing-box 官方 Release 下载 `sing-box-<版本>-windows-amd64.zip`，把以下文件放到：

```
core/sing-box.exe

```

`libcronet.dll` 必须与 `sing-box.exe` 同目录，缺少它内核无法启动。

## 构建

### 构建前必须先打插件补丁

`tools/patch-plugins.ps1` 会做三件事：

1. 修正 Android 插件的 proguard 文件名（AGP 8+ 要求）
2. 给 `flutter_inappwebview_windows` 注入证书指纹校验：把注释掉的证书错误回调启用，并把「放行一切」改成「证书 SHA-256 必须等于 `%LOCALAPPDATA%\HorseBox\panel_pin`」，校验标记 `horsebox-pin-v2`
3. 给 `xterm` 关掉会触发输入法「安全键盘」的标记（`autocorrect` / `enableSuggestions` / `enableIMEPersonalizedLearning`），标记 `horsebox-ime-v2`

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File tools\patch-plugins.ps1
```

`build-all.bat` 每次都会自动调用它；单独构建时请手动执行一次。`flutter pub get` 或升级插件后需要重新执行。

### Windows

```bash
cd UI
flutter pub get
flutter build windows --release --no-tree-shake-icons
```

构建完成后把内核复制进产物：

```bat
windows\package.bat
```

产物在 `UI\build\windows\x64\runner\Release\`。TUN 模式需要以管理员身份运行。

### Android

1. 签名配置

在 `UI/android/` 下创建 `key.properties`：

```properties
storePassword=你的密码
keyPassword=你的密码
keyAlias=horsebox
storeFile=horsebox-release.jks
```

生成 keystore（放在 `UI/android/app/`）：

```bash
keytool -genkeypair -v -keystore horsebox-release.jks -storetype PKCS12 \
  -alias horsebox -keyalg RSA -keysize 4096 -validity 10000
```

`key.properties` 和 `*.jks` 已在 `.gitignore` 中，不要提交。

2. 构建

```bash
cd UI
flutter pub get
flutter build apk --release --no-tree-shake-icons \
  --target-platform android-arm64,android-x64 --split-per-abi
```

产物：`UI/build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`

没有 `key.properties` 时 Gradle 会直接报错，不会静默回退到 debug 签名。

### 一键打包

`build-all.bat` 会依次构建 Windows 和 Android，成品输出到 `app/`。运行前按本机环境修改脚本顶部：

```bat
set "FLUTTER=D:\flutter\bin\flutter.bat"
set "JAVA_HOME=%USERPROFILE%\.jdks\jbr-21.0.11"
set "SDK=%LOCALAPPDATA%\Android\Sdk"
set "NDK_VER=27.2.12479018"
```

用法：

```bat
build-all.bat                 交互式，双端都打
build-all.bat win             只打 Windows
build-all.bat android 3.6     只打 Android，版本 3.6
build-all.bat all 3.6         双端，版本 3.6
```

版本号默认取上一次打包成功后写入的 `.version`（没有则读 `pubspec.yaml`），回车直接沿用。
`--build-name` 使用该版本号，`--build-number` 默认是去掉点的数字。
环境变量：`CLEAN=0` 跳过 clean，`NO_PAUSE=1` 结束后不暂停，`BUILDNO=3014` 固定 versionCode。

注意 `--split-per-abi` 会由 Flutter 给 versionCode 加 ABI 偏移（arm64 +2000、x86_64 +4000），
发布到 F-Droid 前确认新包的 versionCode 大于上一版。

## 使用流程

### 第一次使用：面板还没配好

1. 在服务器上装好 HorseUI，终端会打印管理员密码和面板地址（`https://IP:端口`）
2. 打开 HorseBox →「面板」→「首次登录」
3. 填写面板地址，例如 `https://1.2.3.4:8443`，点「临时连接」
4. 连接是 TLS 加密的，但**这次不校验证书**，页面底部会有一条橙色横幅提示
5. 用管理员密码登录面板，建好入站和用户，复制订阅地址
6. 在面板的「设置 → 客户端证书指纹」里复制 SHA-256 指纹
7. 回到 HorseBox →「订阅」→ 添加订阅，填订阅地址、名称、指纹
8. 回首页点「连接」

从第 7 步开始，面板和订阅都只认这张证书：每次 TLS 握手都会比对指纹，不一致直接断开并提示。

### 已有订阅

- 「订阅」页点击订阅卡片可展开节点列表，右上角圆形按钮刷新
- 面板页直接点订阅条目即可打开面板，走严格指纹校验，不再有临时连接
- 指纹为空时才允许临时连接；填了指纹就不会降级

### 连接

- Windows：TUN 模式需要管理员权限；关闭窗口会隐藏到托盘，代理继续运行
- Android：首次连接会申请 VPN 权限和通知权限；通知栏常驻，可直接在通知里断开

### 分应用代理（Android）

设置 → 代理规则（分应用代理）：

- **代理应用**：只勾选需要走代理的应用；不勾选表示代理全部用户应用
- **直连应用**：强制不进入 VPN，例如国内视频、国内购物
- **系统应用**：默认直连，不显示在列表里；Google Play 服务、Google Services Framework、Play 商店除外，可以手动勾选

保存后需要断开再重连才会生效。

### 分流规则

设置 → 代理规则（分流规则）：

- 内置规则始终生效：`geosite-cn` 和 `geoip-cn` 直连
- 自定义规则支持域名后缀、域名关键字、IP 段，动作可选直连、走代理、拦截
- 规则顺序：自定义规则 → Google 强制代理 → 国内域名/IP → 私有 IP → 其余走代理

### 节点选择与测速

展开订阅卡片后：

- 「自动选择」使用 urltest 按延迟自动挑选
- 点击任意节点可手动切换，当前连接会立即生效
- 节点右侧「测速」显示延迟，顶部「全部测速」批量检测

### 订阅用量

订阅卡片和首页显示「已用 / 总额 / 到期」，**全部以面板为准**：

- 客户端用订阅地址里的令牌，经面板 `/api/clients` 找到该用户，把各个节点的 `used_up + used_down` 相加；
- 总额取 `quota_bytes`（0 表示不限），到期取 `expire_at`（为空表示不限期）；
- 超过 75% 变琥珀色，90% 变红；每 5 分钟、切回前台、连接成功时各刷新一次；
- 面板不可达时保留上一次的值，并标注「更新于 x 分钟前」，不会显示成 0。

前提是「密码本」里有该面板的管理员账号——查询要用它登录面板。客户端不再本地累计流量，两边数字完全一致；真正的配额限制也在面板侧：超出配额后 `/sub` 直接返回 403。

### 配置：SSH 终端

胶囊栏「配置」：

1. 「添加主机」填 IP / 用户名 / 端口（默认 22）/ 密码，备注名可选；
2. 点主机进入全屏终端，顶栏是返回、状态、端口转发、文件传输、重连；
3. 首次连接会记录主机密钥 SHA-256，之后每次比对，不一致直接拒绝；确认换过机器后可在主机菜单里「重置主机指纹」；
4. Android 底部有一行功能键：esc / tab / ^C / ^D / ^Z / 方向键 / `~` `/` `-` `|`。

终端里：

- **Windows**：左键拖拽选中文字，右键出菜单（复制 / 复制全部 / 粘贴 / 取消选中）；
- **Android**：长按选中手指下的词，选区两端各出现一个蓝色光标，拖动任意一端即可扩选（可跨行），随后点悬浮条上的复制 / 粘贴 / 取消；点终端空白处也会取消选区。长按后键盘会自动收起，避免挡住选区和工具条。

### 文件传输（SFTP）

终端顶栏的文件夹按钮进入 SFTP：

- 浏览远端目录，目录在前，显示文件大小；
- 文件右侧「下载」→ 保存到本地（Windows：`下载\HorseBox`；Android：`Android/data/com.horseui.horsebox/files/HorseBox`）；
- 右上「上传」→ 系统文件选择器（可多选），按顺序传到当前目录；
- 「上传」菜单里还可以选「上传文件夹」：整个目录（含子目录、空目录）按原结构传到远端；
- 上传是流式的：本地文件按块读、按块写，几百 MB 的文件也不会占满内存；顶部显示整批进度（第几个 / 共计 / 百分比），可以中途取消；
- **断点续传**：上传中的内容先写在远端 `<文件名>.hbpart`，同时记一份 `.hbpart.meta`（本地大小 + 修改时间），全部写完才改名成正式文件。中途取消、断线或 App 被杀掉，这两个文件会保留（列表里不显示），下次上传同名文件时从已传长度接着写；如果本地文件被改过（大小或修改时间变了），会丢掉旧断点从头传，避免拼出坏文件；
- 断点是按文件记录的，不想要了可以在服务器上 `rm *.hbpart *.hbpart.meta` 清掉；
- 多个文件是一个一个传的，同一时刻只有一个写请求，不会并发压服务器；
- Windows 上可以把文件或文件夹直接拖进窗口，松手即上传到当前目录。

### 端口转发

终端顶栏的左右箭头按钮：

- 规则是「本地端口 → 目标主机:目标端口」，只绑定 `127.0.0.1`；
- 开关即时生效，只在当前连接期间有效，可看到每条规则的当前连接数；
- 规则跟着主机保存，重连后手动打开即可。

### 密码本

胶囊栏「密码本」：一个面板一条记录（面板地址 + 用户名 + 密码），面板地址归一化为 `host:port` 做去重，同一个面板不能重复添加。

在「面板」页右上角点钥匙按钮，下拉选一条记录，账号和密码会直接填进当前登录页的输入框（触发 `input`/`change`，Vue 的 v-model 能收到）。

## 证书与安全

客户端只信任一张证书：面板的 SHA-256 指纹。

- **订阅拉取**：用 `SecureSocket` 握手后直接对 `peerCertificate` 算指纹，任何证书（包括公网 CA 证书）都必须命中
- **面板 WebView（Android）**：每次 `onReceivedServerTrustAuthRequest` 都用回传的证书 DER 算指纹，不一致取消连接
- **面板 WebView（Windows）**：WebView2 的原生证书回调里比对 PEM → DER 的 SHA-256，不一致取消加载
- **临时连接**：只在没有填写指纹时出现，仍然加密，但不做身份校验，用于第一次进面板

指纹从哪里来：面板「设置 → 客户端证书指纹」，或 `GET /api/panelcert`。

换证书（重新生成自签 / 换成 ACME）后，旧指纹会立刻失效，需要重新复制。

> 说明：这套固定只覆盖自签证书。如果面板改用公网 CA 证书，WebView 层不会触发校验回调（证书链本身合法），此时保护来自 CA 体系而不是指纹。

### 本地数据加密

订阅地址（含令牌）和密码本里的密码，落盘前都用 AES-256-GCM 加密，`settings.json` 里只有 `enc1:` 开头的密文。

密钥是首次启动随机生成的 32 字节，写在数据目录的 `secret.key`：Android 在应用私有目录，Windows 在 `%LOCALAPPDATA%\HorseBox`。它能挡住「直接打开配置文件看明文」，但挡不住已经拿到你系统账号权限的人——那种场景需要系统级凭据仓库。

旧版本的明文数据会在下次保存时自动转成密文；换机或删掉 `secret.key` 后旧密文无法解开，需要重新填。

### 设置页结构

设置页只放卡片，点进去才是具体配置：

| 卡片 | 内容 |
|---|---|
| 外观 | 主题模式（跟随系统 / 深色 / 浅色）、主题色（10 个预设 + 自定义色相/饱和度/明度） |
| 代理设置 | 混合端口、TUN、MTU、IPv6、DNS、私有域名映射 |
| 代理规则 | 分流规则、分应用代理（Android） |
| 内核与后台 | 日志级别、自动连接（Windows）、后台驻留入口（Android）、内核版本、数据目录 |
| 备份管理 | 导出 / 导入全部数据（口令加密） |

主题色只影响按钮、开关、进度条这些强调色；深色背景保持中性，换色不会整屏变色。

### 内置输入法

安卓端的输入框默认用内置键盘（不经过系统输入法）：

- 键盘左上「中 / 英」切换；中文模式下字母先进入拼音缓冲，候选条显示在键盘上方；
- 空格上屏第一个候选，点候选词直接上屏；退格先删拼音再删文字；
- 支持全拼（`nihao` → 你好）、前缀补全（`zhongg` → 中国）、首字母（`nh` → 你好）；
- **模糊音**：zh/z、ch/c、sh/s 互通，`zongguo` 也能出「中国」；
- **整句切分**：长串拼音按词库做动态规划，`woaibeijing` → 我爱北京；
- **九宫格**：数字键布局，`64426` → 你好；
- 词库离线内置，约 12.8 万条（单字 + 词组 + 成语 + 现代常用词），不联网、不上传输入；
- 密码框默认英文（可以手动切中文），终端默认英文；
- 「设置 → 内置输入法」可以配默认语言、候选数量、键盘布局、模糊音、整句联想；
- 「全 App 使用内置键盘」打开后，App 内的输入框不再提供切回系统输入法的入口；多行输入（如自定义 DNS）仍走系统键盘。

### 系统输入法

同一个 APK 里还带了一个原生输入法（Kotlin `InputMethodService`），在系统设置里勾选后可以在任何 App 里使用：

- 「设置 → 内置输入法 → 系统输入法」显示当前状态（未启用 / 已启用 / 正在使用），一键跳到系统设置或调出输入法选择器；
- 外观参考 fcitx5：字号偏大（字母 20dp）、9dp 圆角、4dp 键缝，工具栏和候选条用比键盘更深的底色，中间一条 1px 分隔线；主色跟随 App 的主题色；
- **高度和按键大小可调**（「设置 → 内置输入法 → 键盘尺寸」：高度 220–380dp，按键 0.85–1.3 倍，默认 282dp / 1.0 倍），实际高度还会限制在屏高 55% 以内；
- 不走系统 IME 的窗口 inset，横屏也不切全屏——所以不会出现系统键盘把页面顶爆的问题；
- 键盘分三页：**字母页**（纯字母，不混数字）、**数字页**（「123」进入，三个一行）、**符号页**（顶栏「符」进入）；剪贴板、⌨、清空、收起都在顶栏；
- 中文能力相同：全拼、首字母、模糊音、整句切分、九宫格，共用同一份 15.9 万条离线词库（含生僻字、繁体单字与全部 CC-CEDICT 词条）；
- **选字或选词**：候选条是纯文字、第一项用主色加粗；打多音节时除了整词候选，还会给出**首音节单字**（`nihao` → 你好 / 你 / 尼…），点单字只消耗这一段拼音，剩下的留在缓冲里继续选，可以像 fcitx5 那样逐字组词；
- **展开全部候选**：候选条右端的「⌄」点开是一整屏候选（每行五个，最多 60 条），点任意一个直接上屏；
- **长按标点**：字母键按住 380ms 会在键上方弹出 2–4 个标点/符号（q → 「」『』、s → ＋－×÷、z → ①②③…），**按住滑动**选中再松手，松手即上屏；每个字母键下方还有一行小字，提示长按时能打出哪些符号；
- **符号页扩到 5 行**：除 ASCII 符号外，第五行是中文标点（、。，！？：；“”……）；
- **简 / 繁一键切换**：顶栏「简 / 繁」按钮即时切换输出字形，候选和上屏都按繁体显示——用 OpenCC 的 STCharacters 字表逐字转换，词库里的繁体词条优先；
- **英文补全**：英文模式输入字母时，候选条按词频给出补全（内置 37 万词，前 1 万条按 Google 词频排序），点一下整词替换已输入的前缀；密码框不补全；
- **拼音可编辑**：候选条左侧显示已输入的拼音，光标处有一条竖线；**点或拖动拼音区就能把光标移到任意位置**，退格删光标前一个字母，继续输入插在光标处，不用整段删掉重打；
- **主题**：「设置 → 内置输入法 → 键盘主题」两组——**明暗**（跟随 App / 跟随系统）与**主色**（跟随 App / 跟随系统动态取色（Android 12+）/ 自定义：10 个预设 + 色相/饱和度/明度滑杆）；深色是深灰分层（底色 `#1B1C1E`、键 `#35373C`），浅色是白键 + 浅灰底；主色用在回车键、⇧ 高亮、候选首项和拼音提示上；
- **键帽质感**：每个键是「键帽 + 底座」两层——上层键帽上移 2dp、带 1dp 描边，底层用同色深一档；键距缩到 2dp（相邻键之间 4dp），按键更宽更高；**按下时键帽 45ms 内下沉 2dp 压到底座上，松开 90ms 回弹**；
- **按键反馈**：「设置 → 内置输入法 → 按键反馈」可开按键音、按键震动。两者由输入法自己播/自己震（SoundPool + Vibrator），**不跟随系统的「触摸提示音 / 触感反馈」开关**；按键音跟随媒体音量，静音模式下只震不响；**震动强度 20–255 可调**，旁边有「试一下」即时预览，并显示设备诊断（有无马达、系统触感开关、是否支持振幅）；
- **震动兜底**：Android 13 起，系统「触感反馈」关闭时直接调用 `vibrator.vibrate()` 会被静默吞掉，所以这时自动改走 `View.performHapticFeedback(KEYBOARD_TAP, FLAG_IGNORE_GLOBAL_SETTING)`——和小企鹅输入法（fcitx5-android）用的是同一条通道；强度 ≥170 时改用 `LONG_PRESS` 换更沉的震感；
- **一键开系统触感**：按键反馈里有「开启系统触感反馈」按钮，直接写 `Settings.System.HAPTIC_FEEDBACK_ENABLED`（首次需要授予「修改系统设置」）；开启后直连 `vibrator.vibrate()` 生效，振幅滑杆才真正管用；
- 震动时长：振幅可控机型固定 40ms，其余按强度映射到 34–76ms；
- **词频记忆**：选第一项记 +2，翻到后面纠正记 +6，并记录最后一次使用时间——常选的快速上浮，久不用的自然沉下去；
- 密码框自动切英文、不出候选、不学习词频；
- **剪贴板**：顶栏「剪贴板」打开历史（最多 30 条），点一条直接粘贴；只在打开面板时读一次系统剪贴板，不做后台监听；落盘用 `secret.key` 加密（`ime_clipboard.enc`）；
- 代码里没有任何联网逻辑（和主 App 同包，权限上共享 INTERNET，但输入法自身不使用）；
- 顶栏：左侧「中 / 英」，右侧「简 / 繁」+ 五个图标（符号、剪贴板、切换输入法、清空、收起），图标 44dp 见方、21dp 大小，间距比原来大；图标是 Canvas 画的单色矢量，不依赖图标资源；

它是同一个 APK 里的一个 Service，不是独立应用，不需要装第二个包；系统会把它当成一个独立输入法列在「语言和输入法」里。

词库来源与许可：

| 数据 | 用途 | 许可 |
|---|---|---|
| rime-pinyin-simp | 单字/常用词拼音与词频 | Apache-2.0 |
| phrase-pinyin-data | 成语、专有名词拼音 | MIT |
| jieba 词典 | 词频（决定候选排序） | MIT |
| CC-CEDICT | 现代词条补充 | CC BY-SA 4.0 |

只做了格式转换（去声调、合并同词、按词频排序），未改动词条内容；完整说明见 `UI/assets/ime/NOTICE.txt`。

暂不支持：整句的语言模型（只做词库切分，长句可能不如商业输入法自然）、手写、语音。

### 备份与恢复

「设置 → 备份管理」，两步都在这里：

- **导出备份**：设一个至少 8 位的口令，生成一个 `.hbbk` 文件，位置由你自己选（安卓走系统的保存对话框，Windows 走另存为）；
- **导入备份**：选文件、输口令、确认覆盖，App 会关闭，重新打开后生效。

备份包含 `settings.json`、`secret.key` 和 `rules/`，也就是订阅、SSH 主机、密码本、规则，以及全部设置——包括主题模式与自定义主色、内置输入法的默认语言/布局/模糊音/整句联想/全 App 开关、DNS、分流规则等；不包含内核和日志。

导入前的确认框会列出声明的偏好（例如「浅色主题 · 自定义主色 · 中文输入 · 九宫格 · 模糊音」），方便核对备份是不是你想要的那一份。

几个必须知道的点：

- 包里的敏感字段仍是设备密钥加密的，所以包里带着 `secret.key`；外层再用你的口令整体加密（PBKDF2-HMAC-SHA256 20 万次 + AES-256-GCM），**没有口令解不开，口令忘了也找不回**；
- 恢复是**整体覆盖**：先把当前数据目录改名成 `data.backup-<时间戳>`（不删除），再把备份写进去；任何一步失败都会改回来，最坏结果是「没恢复成功，但数据还是原来的」；
- 只在安卓上启动时做一次残留检查：如果上次恢复在改名途中被中断，会自动回滚。

## 常见问题

**连接后国内网站打不开**

检查是否误把国内应用加进了「代理应用」；或者把该应用加到「直连应用」。内置规则只覆盖常见域名/IP。

**Windows 连接失败，提示权限不足**

TUN 需要管理员权限，右键以管理员身份运行。

**面板打不开，提示证书指纹不匹配**

面板重新生成过证书。到面板复制新的 SHA-256，更新订阅里的指纹；临时连接仅在指纹为空时可用。

**Android 代理开着但应用不走代理**

部分应用会绕过 VPN（如自带网络栈的系统组件）。可以尝试关闭该应用的「私密 DNS」，或把它加入「代理应用」。

**终端里打不出字**

桌面端走硬件按键，Android 走系统输入法；两边都不使用内置键盘。

**Android 弹出输入法的「安全键盘」**

安卓上所有密码框都不走系统输入法，改用 App 内置键盘：只有数字、字母和常用符号，没有联想、没有词库、不联网，也不存在安全键盘。

- **App 内密码框**（SSH 主机、密码本）：点一下弹出内置键盘，字符直接写进输入框；
- **面板登录页**：WebView 里的密码框聚焦时，注入脚本挡住系统输入法并通知 App 弹键盘，按键通过 JS 写进当前字段。

键盘固定在屏幕底部，出现时页面和弹窗整体上移、让出这块高度，和系统输入法一样占位，不是浮层。顶部有「粘贴 / 清空 / 收起」。

普通输入（订阅地址、面板地址、SSH 主机/用户名/备注、分流规则等）默认也走内置键盘；键盘顶部多一个「中文」按钮，点了就切回系统输入法，系统键盘收起后再点输入框又回到内置键盘。密码框没有这个按钮。


面板的用户名等普通输入仍走系统输入法（密码已不经过它）。普通输入建议搭配不带云同步的开源输入法，例如「小企鹅输入法」（Fcitx5 for Android）：

<https://f-droid.org/packages/org.fcitx.fcitx5.android/>

密码本身仍建议用密码本一键填入，手动输入越少越好。

**构建时报 `certificate pinning patch missing`**

没有执行 `tools\patch-plugins.ps1`，或 `flutter pub get` 后插件被还原。重新执行补丁脚本再构建。

**Windows 编译报找不到 nuget.exe**

WebView2 的 C++ 依赖用 nuget 还原，把 `nuget.exe` 放到 `tools\` 下（`build-all.bat` 会检查）。

## 已知限制

- Windows TUN 需要管理员权限；权限不足时连接会失败
- Android 的 `system` 栈在部分设备上会卡死，客户端只保留 `mixed` 和 `gvisor`
- Android 分应用代理必须重新连接才生效，TUN 建立后无法动态修改应用列表
- 国内分流依赖内置规则集，HTTPDNS、IP 直连等绕过域名的流量可能仍走代理
- 仓库不包含 `libbox.aar`、`sing-box.exe`、`libcronet.dll`，需要自行准备
- 面板若改用公网 CA 证书，WebView 层不再做指纹校验
- SSH 只支持密码登录（不支持私钥），端口转发只有本地转发（`ssh -L`），没有远程转发和动态 SOCKS
- SFTP 上传支持断点续传和目录上传，下载仍是单文件、不支持续传
